# Website Quan Ly Trung Tam Tieng Anh

## Giới thiệu
*Trung tâm tiếng Anh* chuyên cung cấp các **khóa học chất lượng cao** nhằm phục vụ học viên ôn tập và nâng cao trình độ ngoại ngữ.

## Cấu trúc thư mục
| Thư mục | Nội dung |
| :--- | :--- |
| `archive/` | Chứa dữ liệu lưu trữ cũ của trung tâm |
| `docs/` | Chứa các tài liệu hướng dẫn kỹ thuật |
| `data/` | Chứa các file Excel thông tin học viên và học phí |

## Quy trình đăng ký học tại TTA
1. Tư vấn khóa học phù hợp với trình độ học viên.
2. Điền thông tin vào phiếu đăng ký khóa học.
3. Hoàn tất thanh toán học phí và nhận lịch học chi tiết.
